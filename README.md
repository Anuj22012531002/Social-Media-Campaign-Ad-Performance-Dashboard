# 📊 Social Media Campaign Ad Performance Dashboard

An interactive **Power BI dashboard** designed to analyze social media advertising campaign performance and generate actionable insights from ad events, audience behavior, engagement, and campaign metrics.

## 🎯 Project Objective

The main objective of this project is to analyze social media advertising performance and understand how different campaigns and audience segments contribute to impressions, clicks, engagement, shares, comments, and purchases.

The dashboard helps transform raw advertising data into meaningful business insights using interactive Power BI visualizations and KPIs.

## 📊 Dashboard Pages

### 1. Campaign Overview

Provides a high-level overview of social media campaign performance.

Key metrics include:

- Impressions
- Clicks
- Shares
- Comments
- Purchases
- Engagements
- Campaign performance

### 2. Calendar Tool Tip

Provides time-based analysis of campaign activities and performance.

It helps analyze campaign metrics across different dates and identify changes in advertising performance over time.

### 3. Audience Insights

Analyzes audience-level campaign performance and engagement patterns.

This section helps understand how different audience segments interact with advertisements and contribute to campaign outcomes.
